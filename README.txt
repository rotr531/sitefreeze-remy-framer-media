HOW TO PREVIEW THIS SITE
========================

WINDOWS
  Double-click  preview-windows.bat
  (if SmartScreen warns: More info -> Run anyway)

MACOS
  Double-click  preview-mac.command

  macOS will likely block it the first time
  ("Apple could not verify... free of malware"). This is normal
  for any downloaded script. Click DONE (not Move to Trash), then:

  EASY WAY: open System Settings -> Privacy & Security,
  scroll down - you will see 'preview-mac.command was blocked'.
  Click 'Open Anyway', then confirm. Only needed once.

  TERMINAL WAY (no dialogs): open Terminal, type  sh  followed
  by a space, drag preview-mac.command into the window, press Enter.

Your browser will open  http://127.0.0.1:8123/
To stop the preview: close the terminal window.

No installs or downloads needed - the scripts use tools
built into macOS and Windows.

Alternatively, upload this whole folder to any static hosting
(Cloudflare Pages, Netlify, GitHub Pages, plain FTP) and it just works.
